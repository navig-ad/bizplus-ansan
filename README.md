# 비즈플러스 안산 웹사이트

- 제작·운영: 나빅(NAVIG) / 고객: 회성(會星) 비즈플러스 안산
- 호스팅: GitHub Pages (무료). 빌드 도구 없음, 순수 HTML/CSS.
- 저작권: LICENSE 참고 (All rights reserved, 오픈소스 아님)

## 구조
- `index.html` 모든 문구. 섹션마다 `<!-- ===== -->` 주석으로 구분
- `assets/css/style.css` 디자인. 색은 맨 위 `:root` 변수만 수정
- `assets/img/` 사진(WebP, 긴 변 900~2200px, 장당 300KB 이하 유지)
- 영상은 유튜브 임베드만 (저장소에 영상 파일 올리지 않음)

## 수정 규칙 (나빅 내부)
1. 문구 수정: index.html 해당 섹션만 고치고 커밋
2. 사진 교체: 같은 파일명으로 WebP 덮어쓰기 (원본 JPG 업로드 금지)
3. 요금: 비공개(상담으로만 안내). 공개 지시 전까지 표 넣지 않음
4. 도메인 연결: 고객 가비아에서 DNS만 설정, 저장소에 `CNAME` 파일 추가

## 용량 기준
- 사이트 전체 5MB 이하 목표 (GitHub Pages 한도 1GB 대비 여유)

## 사진 교체 (보정 최종본 나오면)
- 매핑: `tools/photos.json` (사이트 파일명 ↔ 촬영 원본 DSC 번호)
- 실행: `python3 tools/update_photos.py "<최종 보정본 폴더>"` → 같은 파일명으로 덮어써서 HTML 수정 불필요
- 현재 사진은 v3 보정본 기준 임시
